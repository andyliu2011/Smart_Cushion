# 久坐提醒器

基于 **STC89C52RC** 的久坐提醒程序。P1.1 模拟坐下与起立，P1.0 设置休息时长；四位共阳极数码管显示时间，蜂鸣器提供提醒。Keil 工程目前选用兼容的 AT89C52 目标器件进行编译，实际烧录芯片为 STC89C52RC。

**作者：** Andy (Yong) Liu  
**学校：** Sir Winston Churchill Secondary School

> 本文以当前 Timer.c 为准：坐下阶段显示 **正计时**，休息阶段显示 **倒计时**。默认坐下上限为 30 分钟，可切换为 1 分钟测试模式；默认休息时间为 10 分钟。

## 硬件

实物使用 STC89C52RC 和 11.0592 MHz 晶振。程序按 **12T 模式** 计算 Timer0 重装值，每约 1 ms 进入一次中断，负责按键消抖、计时、数码管扫描与蜂鸣。STC89C52RC 支持 6T 和 12T；烧录时需要确认芯片工作在 12T 模式，否则现有计时会明显偏快。参见 [STC89C 系列数据手册](https://www.stcmicro.com/datasheet/STC89C51RC-en.pdf)。

| 功能 | 引脚 | 有效电平 |
| --- | --- | --- |
| 调整休息时间 | P1.0 | 低电平表示按下 |
| 模拟坐下 | P1.1 | 低电平表示坐下，高电平表示起立 |
| 蜂鸣器 | P2.0 | 高电平响 |
| 数码管位选，从左到右 | P2.4、P2.3、P2.2、P2.1 | 高电平选中 |
| 数码管段线 | P0.0～P0.7 | 低电平点亮 |

### 芯片与数码管接线总图

以下 MCU 脚号适用于 **STC89C52RC PDIP-40**；若使用其他封装，应按该封装的数据手册重新对应脚号。数码管的 1～12 脚沿用本项目四位共阳极数码管的接线定义，实际焊接前请核对手中数码管的型号脚位图。

**芯片正面管脚图（缺口朝上，从上方看）：**

    设置开关→GND  P1.0   1 ┌───────∩───────┐ 40  VCC    → +5V
    坐下开关→GND  P1.1   2 │               │ 39  P0.0   → A（数码管11脚）
                  P1.2   3 │               │ 38  P0.1   → F（数码管10脚）
                  P1.3   4 │               │ 37  P0.2   → B（数码管 7脚）
                  P1.4   5 │               │ 36  P0.3   → E（数码管 1脚）
                  P1.5   6 │               │ 35  P0.4   → D（数码管 2脚）
                  P1.6   7 │ STC89C52RC    │ 34  P0.5   → DP（数码管 3脚）
                  P1.7   8 │   PDIP-40     │ 33  P0.6   → C（数码管 4脚）
    复位电路       RST   9 │               │ 32  P0.7   → G（数码管 5脚）
                  P3.0  10 │               │ 31  EA     → +5V
                  P3.1  11 │               │ 30  ALE
                  P3.2  12 │               │ 29  PSEN
                  P3.3  13 │               │ 28  P2.7
                  P3.4  14 │               │ 27  P2.6
                  P3.5  15 │               │ 26  P2.5
                  P3.6  16 │               │ 25  P2.4   → NPN Q1 → COM1（12脚）
                  P3.7  17 │               │ 24  P2.3   → NPN Q2 → COM2（ 9脚）
    晶振一端      XTAL2 18 │               │ 23  P2.2   → NPN Q3 → COM3（ 8脚）
    晶振另一端    XTAL1 19 │               │ 22  P2.1   → NPN Q4 → COM4（ 6脚）
    电源 GND      GND   20 └───────────────┘ 21  P2.0   → 蜂鸣器驱动输入

图中左、右两侧的脚号分别从 **1／40** 向下排到 **20／21**。18、19 脚之间接 **11.0592 MHz 晶振**；9 脚 RST 正常工作时为低电平。P1.0、P1.1 的微动开关直接接 GND，利用芯片内部弱上拉，**没有外接 10K**。P0.0～P0.7 的每条显示 LED 通路已有 **470Ω** 限流，数码管共阳极的 VCC 支路无串联电阻；其他独立 LED 使用 **330Ω**，当前程序没有给它们分配引脚。

代码要求 P2.4～P2.1 **输出 1 时选中对应位**，P0 段线 **输出 0 时点亮**。图中的 NPN C 接 VCC、E 接 COM、B 由 P2 控制，是与该位选极性匹配的推定接法；实际 B／C／E 以及基极电阻须按电路核对。四个 COM 脚不能永久同时接通 VCC，否则无法逐位扫描。

### 数字如何显示

    单位数字的七段位置：

             ── A ──
            │       │
            F       B
            │       │
             ── G ──
            │       │
            E       C
            │       │
             ── D ──   · DP

例如显示 **1**，只点亮 B、C 段，因此选中该位时 P0.2、P0.6 输出 0；显示 **0** 则点亮 A、B、C、D、E、F，G 不亮。要显示 **00:01**，程序依次关闭全部位选、输出第 1 位的段码并选中 COM1，然后对 COM2、COM3、COM4 重复操作。扫描约每 1 ms 换一位，人眼会看到四位同时亮着。代码在扫描第 2、3 位时使用 P0.5 控制时钟点；待机常亮，坐下或休息计时时闪烁。

## 操作

### 待机和设置休息时间

上电后处于待机状态，数码管显示默认休息时间 **10:00**，冒号常亮。每按下一次 P1.0，休息时间增加 1 分钟；可选范围为 1～10 分钟，从 10 分钟再按一次回到 1 分钟。显示立即更新，并保持到开始坐下计时。坐下后及休息期间不能调整。

### 切换坐下上限

待机时，在 **1 秒内完成三次 P1.1 的按下和松开**，坐下上限就在 **30 分钟** 与 **1 分钟测试模式** 之间切换。每次短按需少于约 250 ms；三连按不会启动坐下计时。切换成功后，数码管显示所选上限 **30:00** 或 **01:00** 约 2 秒，然后恢复显示休息时间。再次三连按切回另一档。

### 坐下与起立

持续按住 P1.1 约 250 ms 后开始坐下计时，长按判定期间的时间也计入坐下时间。数码管从 **00:00** 正向计时，冒号每约 500 ms 切换亮灭。松开 P1.1 表示起立，显示切换为休息剩余时间的倒计时，冒号继续闪烁。

**未坐满上限就起立：** 坐下计时暂停，休息倒计时从完整的设定时长开始。若休息未结束就坐回来，本次休息记录清空，坐下计时从此前累计值继续；下次起立重新开始一轮完整的休息倒计时。若一直休息到倒计时结束，坐下累计清零，回到待机。

**坐满上限：** 进入必须休息状态。仍坐着时蜂鸣器持续响；起立后停止长响并开始休息倒计时。休息途中坐回来，倒计时暂停且长响恢复；再次起立后从暂停处继续。只有完成全部离座休息时间，才能调整休息时间并开始下一轮。

休息倒计时结束后，蜂鸣器滴响约 **1 秒**，表示可以开始下一轮。

## 蜂鸣节奏

坐下上限的最后 30 秒开始短响，每次约 50 ms：

| 剩余坐下时间 | 每秒短响次数 |
| --- | --- |
| 30～11 秒 | 1 次 |
| 10 秒 | 1 次 |
| 9 秒 | 2 次 |
| 8 秒 | 3 次 |
| 依次递增 | 每少 1 秒增加 1 次 |
| 1 秒 | 10 次 |

最后一秒的 10 次短响分别在该秒的 0、100、…、900 ms 触发。达到坐下上限时，若仍坐着，转为持续长响。

## 显示规则

| 状态 | 显示内容 | 冒号 |
| --- | --- | --- |
| 待机／调整休息时间 | 当前休息设定，默认 10:00 | 常亮 |
| 切换坐下上限后的约 2 秒 | 30:00 或 01:00 | 常亮 |
| 坐下计时 | 已累计坐下时间，从 00:00 正向计时 | 闪烁 |
| 休息阶段 | 剩余休息时间；强制休息时坐回来会暂停倒计时 | 闪烁 |

## 使用 Keil µVision 3 构建

1. 打开 [Timer.Uv2](Timer.Uv2)。工程包含 [Timer.c](Timer.c) 和 [STARTUP.A51](STARTUP.A51)。Keil 工程目标器件暂选 AT89C52，实际硬件为兼容 8051 指令集的 STC89C52RC。
2. 在 **Options for Target → Target** 中核对时钟设置为 **11.0592 MHz**。工程文件 Timer.Uv2 已设置为 11.0592 MHz；源码中的 Timer0 重装值为 0xFC66，对应传统 12T 8051 的约 1 ms 定时。
3. 构建工程。项目已启用 HEX 输出；构建成功后，使用适用于 STC89C52RC 的 STC-ISP 工具将生成的 Timer.hex 烧录到芯片，并确认 12T 模式。

计时以约 1 ms 的 Timer0 中断为基础，适合提醒用途，未做高精度时钟校准。当前仓库未提供自动化构建或硬件测试脚本。
